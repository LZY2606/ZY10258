# 优化语义见证台

对受限 SSA 片段的重写前后做**有界符号验证**，并生成**可重放反例**的本地服务。
技术栈：Kotlin + Ktor + SQLite + 纯 Web UI（无前端构建）。

## 构建与运行

```bash
# 编译打包
mvn -q -DskipTests package

# 测试 + 演示（端口 5598）
mvn -q test && mvn -q exec:java -Dexec.mainClass=app.MainKt -Dexec.args='--port 5598'
# 打开 http://127.0.0.1:5598 ，页面标题为「优化语义见证台」
```

可选参数：`--port <端口>`（默认 8080）、`--db <SQLite 路径>`（默认 `data/witness.db`）。

## 数据口径

- **整数**：所有整数共享运行期选定的固定位宽（i4 / i8 / i16）。常量与运算结果一律
  按位宽截断环绕，**不使用宿主大整数语义**；溢出判定在位宽语义内完成。
- **溢出旗标**：`STRICT` 下 `nsw`/`nuw` 触发即产生**毒化值**（poison）；`IGNORED` 下旗标被忽略，纯环绕。
- **超宽移位**：移位量 ≥ 位宽时结果为毒化值。
- **毒化值**：穿过大多数运算传播；`select` 只传播被选中臂的毒化；`freeze` 把毒化确定性地
  冻结为 0（保证反例可重放）。毒化到达 `ret` 或分支条件即该输入**未定义（UB）**。
- **浮点**：`IEEE` 模式下 NaN 正常传播；`NNAN` 模式下任何 NaN 结果即毒化；`FAST` 未建模。
  浮点比较按位级进行（NaN 与 NaN 视为相等），因此 `-0.0` 与 `+0.0` 不等。
- **循环**：每个基本块的执行次数受「循环展开上限」约束，超限记为资源上限。

## 求解状态的严格区分

| 状态 | 含义 |
| --- | --- |
| 已证明等价 `EQUIVALENT` | 全部输入枚举完毕且未发现反例 |
| 发现反例 `COUNTEREXAMPLE` | 存在输入使两侧按口径不一致 |
| 资源上限 `RESOURCE_LIMIT` | 循环展开/步数超限 |
| 求解未知 `UNKNOWN` | 输入空间超过枚举预算，求解器放弃（绝不等同于等价） |
| 语义未建模 `UNMODELED` | 片段含未建模指令（如 `fdiv`）或 FAST 浮点模式 |

## 翻译精炼口径

- `REFINEMENT`：源未定义的输入直接跳过（目标可取任意值，**绝不把任意值当作反例**）；
  源有定义而目标 UB，或两侧都有定义但结果不等，判为反例。
- `BOTH_DEFINED`：只在两侧都有定义的输入上比较结果，任一侧 UB 即跳过。

## 反例与重放

反例包含：输入、两侧路径、路径条件、逐条中间值、两侧结果与触发原因
（`target-ub` / `value-mismatch`）。页面上的「缩减反例」会对输入做贪心收缩
（按 popcount/值向更简单值收敛），**原例始终保留**，缩减结果与原例并排展示。
反例确定性：所有语义（含 freeze）都是确定的，同一输入重放结果一致。

## 运行记录、导出与复核

- 每次验证写入 SQLite（`data/witness.db`），首页列出历史记录。
- 「导出全部记录」下载 JSON；「清空数据库」删除全部记录；
  粘贴导出的 JSON 点「导入」即可在清空后重新导入复核。

## Fixture 覆盖

内置重写对覆盖：恒等化简、有符号溢出（两个方向的精炼）、超宽移位（两个方向）、
毒化值/freeze、浮点非数值（-0.0/NaN）、循环展开（资源上限）、输入空间超预算（未知）、
未建模语义（fdiv）。

## 自动化测试

`mvn -q test` 运行 19 个用例，明确验收：反例/未知/等价严格区分、整数固定位宽解析与环绕、
一侧未定义时按精炼口径判定而非随意取值、缩减保持反例有效、SQLite 导出/清空/导入回环。
